# Knowledge Base Business Process

## Tujuan

Menyediakan artikel solusi dan panduan penggunaan layanan IT agar pengguna dapat menyelesaikan masalah secara mandiri.

---

## Actor

### Employee

- Mencari Artikel
- Membaca Artikel
- Memberikan Rating Artikel

### IT Staff

- Membuat Artikel
- Mengubah Artikel
- Mengarsipkan Artikel

### IT Supervisor

- Review Artikel
- Approval Artikel
- Monitoring Artikel

### IT Manager

- Monitoring Knowledge Usage
- Monitoring Knowledge Quality

---

## Knowledge Category

- Account
- Email
- VPN
- Printer
- Network
- Application
- Server
- Security

---

## Knowledge Article Lifecycle

Draft

↓

Review

↓

Approved

↓

Published

↓

Archived

---

## Article Creation Flow

1. IT Staff membuat artikel

2. Artikel berstatus Draft

3. Supervisor melakukan review

4. Artikel disetujui

5. Artikel dipublish

6. User dapat mengakses artikel

---

## Knowledge Search Flow

1. User membuka Knowledge Base

2. User memasukkan keyword

3. Sistem mencari artikel

4. Artikel ditampilkan

5. User membaca artikel

6. View Counter bertambah

---

## Article Rating Flow

1. User membaca artikel

2. User memberikan rating

3. Sistem menyimpan rating

4. Sistem menghitung rata-rata rating

5. Supervisor melakukan evaluasi artikel

---

## Related Article Flow

1. User membuka artikel

2. Sistem mencari artikel terkait

3. Artikel terkait ditampilkan

4. User dapat membuka artikel lain

---

## Output

- Knowledge Article tersedia
- Knowledge Category tersedia
- Article Rating tersedia
- Article View Counter tersedia
- Related Article tersedia
- Knowledge Report tersedia
